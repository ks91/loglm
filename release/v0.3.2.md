## loglm v0.3.2

This release simplifies switching coding agents by installing missing prompt
agents for the destination, and documents upgrades that preserve project data.

### Highlights

- `loglm --agent` now installs missing prompt agents registered by loglm for
  the previously selected coding agent in the current project. Installation
  uses the original GitHub or local sources and destination-compatible prompt
  files.
- Add `loglm --agent-only` to switch coding agents without installing prompt
  agents.
- Keep existing destination registrations with a local prompt file unchanged.
  If a transfer fails, stop before launch and retain the previous coding-agent
  selection. Successful partial installations remain available for a retry.
- Document uninstall/reinstall upgrades, preserved project data, custom
  installation locations, and recovery from download failures.

### Compatibility Notes

- The default behavior of `--agent` has changed. Use `--agent-only` for the
  previous selection-only behavior.
- GitHub prompt-agent sources require network access. Local source directories
  must still be available. Manual instructions outside loglm-managed blocks
  are not transferred.
- Switching does not remove prompt agents already installed for the destination.
- Normal launches without either switching option do not trigger a transfer.

### Validation

- Shell syntax checks and the full local regression suite pass.
- Regression coverage includes multiple prompt agents, local paths containing
  spaces, destination-specific prompt files, existing installations, shared
  instruction files, opt-out, and recovery after failed transfers.
- Coding-agent switching was also tested successfully by the maintainer in
  their working environment.

### Install / Upgrade

For a first installation:

```bash
curl -fsSL https://raw.githubusercontent.com/ks91/loglm/main/install.sh | bash
```

For an upgrade, exit running loglm sessions and run the following in a regular
Bash or Zsh terminal:

```bash
(
  set -e
  set -o pipefail
  curl -fsSL https://raw.githubusercontent.com/ks91/loglm/main/uninstall.sh | bash
  curl -fsSL https://raw.githubusercontent.com/ks91/loglm/main/install.sh | bash
) && hash -r && loglm --version
```

Project logs, settings, prompt agents, project instructions, and coding agent
applications are preserved. Export the same `LOGLM_INSTALL_DIR` and/or
`LOGLM_HOME` first if using custom installation locations. If installation
fails, restore connectivity and rerun the installation command. There is no
automatic rollback. See the README's Upgrade section for details.
