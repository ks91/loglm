## loglm v0.2.1

This is a bugfix release for experimental OpenClaw and Hermes Agent
prompt-agent integration.

### Fixes

- Scoped OpenClaw and Hermes Agent prompt-agent reference blocks.
  - Installed prompt files such as `GAMER-PAT.md` are now followed only when
    the corresponding skill/prompt-agent workflow is selected.
  - This prevents unrelated OpenClaw/Hermes skills from being forced to follow
    an installed prompt-agent file.
- Codex, Claude Code, and Gemini prompt-agent behavior remains unchanged.
  - They still treat installed prompt-agent files as primary project
    instructions in the target directory.

### Validation

- Added regression coverage for scoped OpenClaw/Hermes prompt-agent references.
- Existing Codex, Claude Code, Gemini, OpenClaw, Hermes, PII redaction, and
  timeline regression checks pass.
- Confirmed Hermes Agent + GAMER PAT prompt-agent installation on a macOS VM.

### Install / Uninstall

```bash
curl -fsSL https://raw.githubusercontent.com/ks91/loglm/main/install.sh | bash
curl -fsSL https://raw.githubusercontent.com/ks91/loglm/main/uninstall.sh | bash
```
