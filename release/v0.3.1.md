## loglm v0.3.1

This release improves decoded transcript fidelity for Codex, Claude Code, and
Antigravity, and adds optional DuckDuckGo MCP setup for Local LLM sessions.

### Highlights

- Reconstruct Codex full-screen terminal updates while preserving legacy inline
  decoding. Reduce repeated redraws and exclude unfinished input fragments.
- Improve Claude Code inline redraw handling to preserve multiline prompts and
  transcript text while removing overwritten animation frames.
- Reconstruct Antigravity inline cursor updates. Preserve short code lines,
  indentation, closing braces, repeated code, and genuinely repeated prompts.
  Keep the final response after exit/resume hints.
- Offer DuckDuckGo MCP web search during Local LLM setup. With user consent,
  install `uv` when needed and register `ddg-search` with Claude Code using
  `--scope local`.
- Include configured DuckDuckGo search guidance in managed `CLAUDE.md` notes.

### Compatibility Notes

- Terminal reconstruction is selected from recorded UI patterns, not a pinned
  coding-agent version. Other recordings use stream decoding and may retain
  redraw artifacts.
- Only text emitted to the terminal can be recovered. Details that were never
  displayed cannot be reconstructed.
- Antigravity and Local LLM support remain experimental. DuckDuckGo setup is
  optional and does not enable Claude's built-in Web Search for local models.
- Re-decode existing raw logs with the updated `loglm-decode` to benefit from
  these improvements. Raw logs are not modified.

### Validation

- Shell syntax checks and the full local regression suite pass.
- Added synthetic regression coverage for terminal redraws, repeated prompts,
  code preservation, and final-response retention.
- Checked real Codex, Claude Code, and Antigravity recordings, including older
  recordings when available.
- The final Antigravity-specific changes leave the compared Codex, Claude Code,
  and legacy Gemini sample outputs unchanged.
