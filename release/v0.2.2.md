## loglm v0.2.2

This is a bugfix release for Claude Code resume detection.

### Fixes

- Fixed Claude Code automatic resume detection for project paths containing
  non-ASCII characters such as Japanese directory names.
  - `loglm` now matches Claude Code's Unicode-aware project path encoding.
  - This restores automatic `claude --continue` behavior in directories such as
    paths containing `早稲田大学`.
- Codex and Gemini launch behavior is unchanged.
  - They already delegate resume selection to their own CLIs.

### Validation

- Added regression coverage for Claude Code history detection with spaces,
  tildes, and Unicode characters in the project path.
- Existing Codex, Claude Code, Gemini, OpenClaw, Hermes, PII redaction, and
  timeline regression checks pass.

### Install / Uninstall

```bash
curl -fsSL https://raw.githubusercontent.com/ks91/loglm/main/install.sh | bash
curl -fsSL https://raw.githubusercontent.com/ks91/loglm/main/uninstall.sh | bash
```
