## loglm v0.3.0

This release adds experimental Local LLM support and replaces the Gemini CLI
launch target with Google Antigravity CLI support.

### Highlights

- Added experimental Local LLM support through Claude Code
  - selectable as `local-llm`
  - runs `claude` with `ANTHROPIC_BASE_URL` pointing to a local
    Anthropic-compatible gateway such as `llama-server`
  - supports per-directory `--local-llm-url` and `--local-llm-model`
  - can auto-detect the model name from `<local-llm-url>/v1/models`
  - writes `.claude/settings.local.json` to disable Claude Code attribution
    headers for llama.cpp compatibility
- Replaced the Gemini CLI launch target with experimental Antigravity support
  - selectable as `antigravity`
  - launches `agy -c` by default to continue the previous conversation
  - `--new` launches `agy` without `-c`
  - installs on macOS via Homebrew cask `antigravity-cli` when available
  - installs on Ubuntu/Linux-family systems via the official installer:
    `curl -fsSL https://antigravity.google/cli/install.sh | bash`
- Updated prompt-agent support for Antigravity
  - uses `AGENTS.md` as the target instruction file
  - resolves source files as
    `AGENT_INSTALL_ANTIGRAVITY.md` -> `AGENT_INSTALL_GEMINI.md` -> `AGENT_INSTALL.md`
  - keeps `AGENT_INSTALL_GEMINI.md` as a compatibility fallback for older
    Google/Gemini prompt-agent sources
- Improved decoded log readability
  - better Claude Code expanded thinking block decoding
  - keeps Claude prompt lines that contain `ing` words instead of treating them
    as status noise
  - adds Antigravity log cleanup and final redraw preservation
  - maps `local-llm` logs to Claude-style decoding
- Documented optional DuckDuckGo MCP setup for Local LLM / Claude Code users
  who want lightweight web search support.

### Compatibility Notes

- `gemini` is no longer a supported launch target in `loglm`.
  - Existing Gemini log decoding fixtures remain so old logs can still be read.
  - Use `antigravity` for the Google/Gemini-family coding agent path.
- Antigravity support is experimental.
  - The CLI has been tested via Homebrew on macOS and via the official installer
    on Ubuntu on Lima.
  - Upstream Antigravity CLI behavior may still change.
- Local LLM support is experimental.
  - It depends on Claude Code accepting a local Anthropic-compatible endpoint.
  - Claude Web Search is not available through this route; MCP-based search is
    optional and user-configured.

### Platform Status

- Existing stable targets remain:
  - macOS
  - Ubuntu
  - Ubuntu on Lima (macOS)
  - Ubuntu on WSL2
  - Raspberry Pi OS
  - Chrome OS Linux container / Crostini
- Antigravity and Local LLM support are experimental across supported platforms.

### Validation

- Added regression coverage for Local LLM launch/configuration.
- Added regression coverage for Antigravity launch and prompt-agent setup.
- Added regression coverage for Claude/local-LLM thinking block decoding.
- Added regression coverage for Antigravity decoded log cleanup.
- Existing Codex, Claude Code, OpenClaw, Hermes, PII redaction, and timeline
  regression checks pass.
